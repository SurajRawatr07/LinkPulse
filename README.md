### 📂 Screenshot Directory

Save your actual application screenshots using this structure:

```text
docs/
└── screenshots/
    ├── links.png
    ├── analytics.png
    ├── qr-code.png
    └── campaigns.png
```

**How to add your screenshots**

1. Open the [LinkPulse website](https://linkpulse2026.vercel.app/).
2. Visit each feature that is available in your application.
3. Capture screenshots using `Win + Shift + S` on Windows.
4. Save the images with the filenames shown above.
5. Upload the `docs/screenshots/` folder to your GitHub repository.

> The live preview uses an external screenshot service. The other image
> paths require real screenshot files in your repository; remove any
> image reference for a feature that is not available in your build.
